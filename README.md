# 聲音的形狀

對著麥克風說話、唱歌或拍手，看見聲音的 3D 形狀。

**網址：<https://marskuan.github.io/sound-shape/>**（手機、電腦都可以開）

## 怎麼用

打開網頁就會開始。瀏覽器會跳出「要不要允許使用麥克風」，按「允許」，然後對著它說話、唱歌或拍手。

聲音只在你的手機或電腦裡即時分析，**不錄音、不儲存、不上傳**。

## 兩個畫面

- **圖表**：橫向是時間（右邊是現在），上下是音高，前後是音色（悶 ↔ 尖亮）。點的大小是響度，濃淡是「有清楚的音高」或「雜音」，連線是同一個連續的聲音。
- **發射**：聲音從中間的發射點射出去。上下 = 音高（比你平常的音高高就往上），左右 = 音色，越遠 = 越大聲。

## 操作

| | 手機 | 電腦 |
|---|---|---|
| 旋轉 | 單指拖 | 左鍵拖 |
| 縮放 | 雙指捏 | 滾輪 |
| 移動 | 雙指拖 | 右鍵拖 |
| 回到中心 | 連點兩下 | 連點兩下，或按 `.` |

## 說明

純靜態網頁，一個 `index.html`，沒有後端。3D 用 [Three.js](https://threejs.org/)，音高用自相關法、音色亮度用頻譜重心，全部在瀏覽器裡算。

網頁裡的「怎麼看 → 背後的理論」列了各軸對應的文獻。這是依文獻做的設計對照，各軸怎麼對應是詮釋，不等於這些文獻自己使用的軸。
