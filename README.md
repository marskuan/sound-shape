# 聲音的形狀

用麥克風把你的聲音即時變成 3D 的形狀。

- **X 軸**：時間（新的在右）
- **Y 軸**：音高
- **Z 軸**：亮度（頻譜重心）
- **點的大小**：響度
- **墨的濃淡**：有明確音高的濃，噪音的淡
- **連線**：一段連續的聲音

## 使用

打開網頁，按下方的「麥克風」並允許權限。沒有麥克風可以先看「示範」。

聲音只在你的瀏覽器裡分析（Web Audio API），不會傳到任何地方。

## 說明

畫面右邊的「理論對照」列出每個視覺元素對應的文獻脈絡（Smalley、Grey、Schaeffer 等）。
軸的選擇是設計上的詮釋，不等於這些文獻自己用的軸。

單一檔案：`index.html`。3D 用 [Three.js](https://threejs.org/)（從 CDN 載入），字體用 Google Fonts 的 Shippori Mincho。
