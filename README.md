# 聲音的形狀

對著麥克風說話、唱歌或拍手，看見聲音的 3D 形狀。

**網址：<https://marskuan.github.io/sound-shape/>**（手機、電腦都可以開）

## 怎麼用

打開網頁就會開始。瀏覽器會跳出「要不要允許使用麥克風」，按「允許」，然後對著它說話、唱歌或拍手。

聲音只在你的手機或電腦裡即時分析，**不錄音、不儲存、不上傳**。

## 五種模型

底部的「**模型**」按鈕可以切換（也可以按數字鍵 1–5）。每一種是把聲音變成 3D 的不同做法：

| | 模型 | 做法 |
|---|---|---|
| 01 | **圖表** | 橫向是時間（右邊是現在），上下是音高，前後是音色（悶 ↔ 尖亮）。點的大小是響度，濃淡是「有清楚的音高」或「雜音」。 |
| 02 | **發射** | 聲音從中間一個點射出去：上下 = 音高，左右 = 音色，越遠 = 越大聲。 |
| 03 | **年輪** | 十二個音名（C 到 B）繞成一圈，高一個八度就往上疊一層，時間往外擴。唱音階會看到點沿著螺旋爬升。 |
| 04 | **水面** | 每個聲音落在水面，擴成一圈圈漣漪：落點由音高和音色決定，越大聲波越高。 |
| 05 | **山脈** | 每一刻的頻譜畫成一條線（橫向是頻率，高度是強度），疊成一排山；新的在前，舊的往遠方退，後面的線被前面的山遮住。 |

## 點雲與顏色

有「點」的三個模型（圖表、發射、年輪），每個聲音是一小團很細的粒子，不是一顆圓點。每顆粒子的顏色**只由它所在的位置決定**：同一個位置永遠是同一個顏色，不同位置顏色不同。顏色、粒子的大小和形狀，依各模型的理論各有一套：

| 模型 | 顏色怎麼來（參考 Wes Anderson） | 粒子的大小和形狀 |
|---|---|---|
| 圖表 | 位置，主要是音高；*The Grand Budapest Hotel*（酒紅、灰藍、粉、珊瑚、橙、蜜金） | 像一把砂：細小的實心顆粒；越大聲，顆粒和整團都越大 |
| 發射 | 離發射口的距離；*The Life Aquatic with Steve Zissou*（朱紅、琥珀、黃、淺海藍、深海藍） | 剛射出是細小明亮的火星，越遠稍微變大、越淡（不加霧、不加暈） |
| 年輪 | 繞中軸的角度（音名），每個 C 都同色；*The Darjeeling Limited* 頭尾相接；高度（八度）→ 明暗 | 細點排成順著年輪的弧；低音的點較大，越高越小（音高 ↔ 大小，Mondloch & Maurer 2004） |

點的濃淡仍然是「有沒有清楚的音高」。

**山脈**的線也有顏色，同樣只由位置決定：主要看高度，谷底灰青，往上是天藍、粉、奶油黃，最高的峰是赭橙（參考 *Moonrise Kingdom*）。水面沒有點，維持單色細線。

**背景和文字：** 黑底白字，不分白天夜裡；淡一點的字和細線是白色壓暗的灰，只有一點珊瑚紅當強調。

畫面跑不動時（手機、舊電腦），會自動降低解析度和點數。

## 操作

| | 手機 | 電腦 |
|---|---|---|
| 旋轉 | 單指拖 | 左鍵拖 |
| 縮放 | 雙指捏 | 滾輪 |
| 移動 | 雙指拖 | 右鍵拖 |
| 回到中心 | 連點兩下 | 連點兩下，或按 `.` |
| 切換模型 | 按底部的「模型」 | 按「模型」，或按數字鍵 1–5 |

## 說明

純靜態網頁，一個 `index.html`，沒有後端。字型是 Google Fonts 的昭源宋體（標題）、昭源黑體（內文）和 Jost（英文、數字）；載不到時退回系統的明體和黑體。3D 用 [Three.js](https://threejs.org/)，音高用自相關法、音色亮度用頻譜重心，全部在瀏覽器裡算。

網頁右邊的「理論對照」列了各軸對應的文獻。這是依文獻做的設計對照，各軸怎麼對應是詮釋，不等於這些文獻自己使用的軸。
