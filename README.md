# 聲音的形狀

用麥克風把你的聲音即時變成 3D 的形狀。

- **X 軸**：時間（新的在右）
- **Y 軸**：音高
- **Z 軸**：亮度（頻譜重心）
- **點的大小**：響度
- **墨的濃淡**：有明確音高的濃，噪音的淡
- **連線**：一段連續的聲音

## 使用

打開網頁，按「開始」：

1. 如果你有接 MAX9814（接在 Arduino Nano 或 Raspberry Pi Pico 上，用 USB 連電腦），而且之前允許過，就自動用它。
2. 找不到、或中途拔掉，就用這台電腦的麥克風。

沒有麥克風可以先看「示範」。

第一次要用 MAX9814，按「接 MAX9814」，在跳出的視窗選一次裝置（瀏覽器的安全規定）。之後會自動接上。這個功能用的是 Web Serial，目前只有 Chrome、Edge 支援；其他瀏覽器會直接用電腦麥克風。

聲音只在你的瀏覽器裡分析，不會傳到任何地方。

## MAX9814 的程式

- Nano：序列埠 500000 baud，收到 `A1` 開始傳 8 位元取樣（約 19231 Hz），`A0` 停止。
- Pico 2：兩顆 MAX9814 在 GP26／GP27，USB 序列埠傳封包，開頭 `A5 5A A5 5A`，後面 256 格 × (左、右各 int16)，48 kHz。

## 說明

畫面右邊的「理論對照」列出每個視覺元素對應的文獻脈絡（Smalley、Grey、Schaeffer 等）。
軸的選擇是設計上的詮釋，不等於這些文獻自己用的軸。
